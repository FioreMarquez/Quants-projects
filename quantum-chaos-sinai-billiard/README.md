# Quantum Chaos & BGS Conjecture — Sinai Billiard

Numerical verification of the Bohigas–Giannoni–Schmit (BGS) conjecture via first-principles numerical linear algebra:
- Symmetrized Shortley–Weller finite-difference discretization of the Helmholtz operator.
- Shift-and-Invert Krylov eigensolver with $PA=LU$ partial pivoting and explicit reorthogonalization.
- Weyl-law unfolding via Householder QR least squares and Random Matrix Theory statistics (P(s), Delta_3(L)).
